# FLINK-DEMO

This cluster is a demo environment for showcasing Confluent Platform and Apache Flink workloads.

## Domain

All services are accessible under the `flink-demo.confluentdemo.local` domain:

- ArgoCD: `argocd.flink-demo.confluentdemo.local`
- Control Center: `controlcenter.flink-demo.confluentdemo.local`
- Grafana: `grafana.flink-demo.confluentdemo.local`
- Prometheus: `prometheus.flink-demo.confluentdemo.local`
- Alertmanager: `alertmanager.flink-demo.confluentdemo.local`

## Cluster setup

Follow the cluster onboarding guide: `docs/cluster-onboarding.md`
